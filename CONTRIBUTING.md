# Contributing to the Plywise engine

Thanks for helping. Bug reports, failing specs, hardware data corrections and pull requests are all welcome.

- Run `npm test` and `node test/fuzz.ts` in `engine/` before sending a pull request. A change to a design rule should come with a test.
- Hardware numbers (Blum drilling patterns and the like) need a source: link the manufacturer's published spec.
